# Tax Engine

A modular, CLI-first Python engine for German income tax preparation (*Einkommensteuererklärung*), automated declaration audits, and integration with the official ELSTER Rich Client (ERiC) interface.

## Overview

This project provides a developer-friendly framework to:
- Compute German statutory allowances and deductions (commute allowance, Homeoffice-Pauschale, digital equipment depreciation, disability allowances under § 33b EStG).
- Run automated multi-agent pre-submission plausibility audits.
- Interface with the official ELSTER ERiC C-library for local schema validation and encrypted transmission.

## Status

Project under active initial architecture and development.
